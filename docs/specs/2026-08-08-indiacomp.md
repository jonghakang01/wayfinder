# India Comp Calculator (인도 인력 비용 계산기)
- 상태: approved (2026-08-08 강프로: TP 18%, Chennai 하이어링. 나머지는 기본값으로 시작)
- 대상: 신규 앱 (slug: indiacomp, 홈 메뉴 💼 업무 그룹)

## 문제
인도 인력 온보딩 시 비용 구조가 여러 층으로 겹쳐 한눈에 안 보인다 (강프로 관찰):
- 오퍼는 LPA(lakh/년, 1 lakh=₹100,000) + CTC 관행어로 오간다 — 익숙하지 않은 단위·용어
- 오퍼 금액 위에 보험 등 고용주 부담 비용이 더 붙는다
- 미국 법인이 인도 법인에 지급할 때 TP(transfer pricing) 마크업이 붙는다
- 내부 검토는 전부 USD 기준이라 매번 환산이 필요하다
현재는 이걸 머릿속/엑셀로 매번 따로 계산 → 오퍼 검토가 느리고 실수 여지.

## 목표
후보 1명의 오퍼(LPA)를 입력하면 다음 4단이 한 화면에 단계별로 보인다:
1. **Offer (CTC)** — LPA ↔ ₹ 연/월 자동 표기
2. **India Entity Cost** — CTC + 고용주 추가 부담(보험 등, % 또는 항목별)
3. **US Charge (TP)** — India Cost × (1 + TP 마크업 %)
4. **USD View** — 위 전부를 입력 환율로 USD 환산 (연/월)
후보 여러 명을 저장해 나란히 비교할 수 있다.

## 비목표 (이번엔 안 한다)
- 인도 세법 정밀 계산(PF/gratuity/TDS 법정 요율 자동화) — 사용자가 %/금액으로 입력하는 근사치로 시작
- 실시간 환율 API 연동 — 수동 입력(마지막 값 기억). 필요해지면 별건
- 오퍼레터 문서 생성, 급여명세 관리, 승인 워크플로
- 다국가 확장(인도 외 국가)

## 사용자 흐름
1. 홈 → 💼 India Comp 진입
2. 상단 접이식 인테이크: 이름/역할, 오퍼 LPA, 고용주 부담 %(또는 항목), TP %, 환율(₹/USD)
3. Add → 4단 카드(Offer→India Cost→US Charge→USD)가 즉시 계산되어 표시
4. 저장된 후보 리스트에서 비교·수정·삭제. 값 바꾸면 즉시 재계산

## 데이터
- 신규 파일: `~/.appdata/indiacomp/<data_key>.json`
- 구조: `{settings: {tp_pct, burden_pct, fx_rate}, candidates: [{id, name, role, lpa, burden_override, note, created}]}`
- 마이그레이션: 없음 (신규 앱)
- 롤백: 파일 무시되므로 안전

## 확정값 (2026-08-08 강프로 답변 + 기본값 합의)
- TP 마크업 기본값 **18%** (강프로 확인, 편집 가능)
- 하이어링 지역: **Chennai** — 후보 카드에 location 기본값 Chennai 표기 (계산에는 미사용)
- 오퍼 기준: **CTC로 가정** (인도 표준 관행, 강프로 미확정 → UI에 "Offer (CTC)" 라벨로 명시해 오해 방지)
- 고용주 추가 부담 기본값 **10%** (미확정 근사치 — 편집 가능, 라벨에 "insurance & extras" 명시)
- 환율: 수동 입력, 마지막 값 기억 (초기 placeholder 88.0 ₹/USD)
- Q5(오퍼 문구 자동 생성)는 v1 제외 — 후속 후보로 보류
